# 🎓 Student of the Month Certificate Generator

> A responsive, print-ready web application designed for teachers and school administrators to quickly generate, customize, and print professional "Student of the Month" certificates.

---

## 🌟 Key Features

* **4 Design Themes**: Choose from *Royal Navy & Gold*, *Classic Parchment*, *Modern Emerald*, and *Vibrant School*.
* **Exact A4 Landscape Precision**: Engineered with strict CSS `@media print` rules for single-page A4 landscape output without bottom overflow.
* **Handwritten Blanks Mode**: Toggle between digital text or clean, guided blank lines for handwritten entries.
* **Student Photo Framing**: Upload student photos with circle, rounded, or square framing and interactive zoom options.
* **Signature Flexibility**: Support for auto-styled calligraphic script or custom digital signature uploads.
* **One-Click PDF Export**: Integrated high-resolution PDF download using `html2pdf.js`.

---

## 🚀 Quick Start

1. Clone or download this repository.
2. Open `index.html` in any standard web browser.
3. Use the sidebar to enter student details, photo, and commendations.
4. Click **Print** or **Download PDF**.
